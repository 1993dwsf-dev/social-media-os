1. PUBLICAR AS FUNÇÕES DO CONVEX E GERAR OS TIPOS
--------------------------------------------------------------------------------
Toda mudança em src/convex/ precisa disto antes de rodar o typecheck:

    bun convex dev --once

  - "--once" é obrigatório: sem ele o comando fica interativo e trava.
  - Saída esperada: "Convex functions ready!".
  - Só publicam na implantação de DEV. Produção é pelo botão Publicar do Freebuff.

Rodar as três verificações de uma vez (o comando usado no dia a dia):

    bun convex dev --once && bun tsc -b --noEmit && bun test && bunx eslint src tests --quiet

    bun tsc -b --noEmit

--------------------------------------------------------------------------------
3. FUNÇÕES INTERNAS (o cliente NÃO alcança — rodar pelo painel ou CLI)
--------------------------------------------------------------------------------
Todas exigem o nome no formato "módulo:função".

--- Limpeza de sessões inativas (também roda no cron diário) ---

    npx convex run sessions:cleanupInactiveSessions '{}'

  Devolve: { sessions, refreshTokens } com o que foi apagado.
  Idempotente: rodar de novo devolve { sessions: 0, refreshTokens: 0 }.

--- Reparo das faturas antigas gravadas sem clientId (ver §8.5 do docs/entrega.md) ---

  1) SIMULAÇÃO — não escreve nada, mostra o relatório:

    npx convex run repair:relinkOrphanInvoices '{}'

  2) GRAVAÇÃO — só depois de ler o relatório:

    npx convex run repair:relinkOrphanInvoices '{"apply":true}'

  Relatório devolvido:
    { dryRun, scanned, relinked, matchedCount, matched, skippedCount, skipped }

  Motivos de "skipped" (ficam para decisão humana):
    unmatched     — descrição fora do padrão ou cliente que não existe mais
    ambiguous     — dois clientes com mesmo nome E mesma mensalidade
    fee-mismatch  — nome bate, mas o valor não é a mensalidade
    duplicate     — religar criaria a segunda fatura do mesmo cliente no mesmo mês


--------------------------------------------------------------------------------
4. CONTAGEM DE FUNÇÕES DA API (inventário)
--------------------------------------------------------------------------------
Das 45 funções: 5 internas e 5 respondem sem sessão.
O tests/no-session.test.ts falha se alguma função nova não for classificada lá.

    bun -e '
    const mods = { auth: await import("./src/convex/auth"), demo: await import("./src/convex/demo"), portal: await import("./src/convex/portal"), repair: await import("./src/convex/repair"), sessions: await import("./src/convex/sessions"), turnstile: await import("./src/convex/turnstile"), users: await import("./src/convex/users") };
    let total = 0, internal = 0, open = 0;
    for (const ns of Object.values(mods)) {
      for (const fn of Object.values(ns)) {
        const f = fn;
        if (!f || !(f.isQuery || f.isMutation || f.isAction)) continue;
        total++;
        if (f.isInternal === true) internal++; else open++;
      }
    }
    console.log("total=" + total, "internal=" + internal, "open=" + open);'
